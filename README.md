
Cервис предоставляет базовые функции для работы с банковскими счетами, картами, переводами и кредитами.

## Как пользоваться сервисом

1. **Запуск сервиса:**

   Для запуска сервиса, в корне проекта выполните команду:

   ```bash
   go run entrypoint.go
   ```

   Сервис будет доступен по адресу: `http://localhost:8080`.

2. **Регистрация клиента:**

   Для регистрации нового клиента используйте эндпоинт:

    * **POST** `/register`
      Пример запроса:

   ```json
   {
       "email": "client@example.com",
       "username": "client1",
       "password": "securePassword123"
   }
   ```

3. **Аутентификация клиента (получение токена):**

   Для входа в систему используйте эндпоинт:

    * **POST** `/login`
      Пример запроса:

   ```json
   {
       "username": "client1",
       "password": "securePassword123"
   }
   ```

   В ответ вы получите **JWT-токен** для дальнейших запросов.

4. **Создание счета:**

   Для создания счета используйте эндпоинт:

    * **POST** `/wallet`
      Пример запроса:

   ```json
   {
       "clientID": "123",
       "currency": "RUB"
   }
   ```

5. **Пополнение счета:**

   Для пополнения счета используйте эндпоинт:

    * **POST** `/wallet/deposit`
      Пример запроса:

   ```json
   {
       "accountID": "12345",
       "amount": 1000
   }
   ```

6. **Перевод средств между счетами:**

   Для перевода средств используйте эндпоинт:

    * **POST** `/transfer`
      Пример запроса:

   ```json
   {
       "fromAccountID": "12345",
       "toAccountID": "67890",
       "amount": 500
   }
   ```

---

## Поддерживаемые команды

### Публичные команды:

* **POST** `/register` — регистрация клиента.
* **POST** `/login` — аутентификация и получение JWT-токена.

### Защищенные команды (требуют JWT):

* **POST** `/wallet` — создание счета.
* **POST** `/wallet/deposit` — пополнение счета.
* **POST** `/transfer` — перевод средств между счетами.
